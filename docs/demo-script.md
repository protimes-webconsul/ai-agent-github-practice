## 01 取得・確認（スライド8・9）

AIへの依頼：

```
このリポジトリを C:\work の中へクローンしてください。
https://github.com/protimes-webconsul/ai-agent-github-practice
完了後：保存先・リポジトリ名・現在のブランチを教えてください。
```

確認すること：

- [ ] `C:\work\ai-agent-github-practice` が1つだけできた
- [ ] `index.html` などのファイルが見える
- [ ] 現在のブランチが `main`

> 2回目以降は再クローンせず、同じフォルダでプル（スライド9）。

## 02 準備（スライド11：5点セット）

```
作業を始める前に、現在のフォルダ、リポジトリ、ブランチ、未コミットの変更を一覧で教えてください。
そのあと main を最新化し、fix/contact-button という作業ブランチを作成してください。
```

- [ ] 場所：`ai-agent-github-practice`
- [ ] 状態：未コミットの変更なし
- [ ] 最新化：`main` をプル済み
- [ ] 分岐：`fix/contact-button` にいる

## 03 AIで修正（スライド12・13）

```
目的：お問い合わせボタンの文言を分かりやすくする
範囲：index.html の id="contact-button" の文言だけを「無料相談はこちら」に変更。色・位置・リンク先は変更しない
確認：変更ファイルと差分を説明してください
Git：現在のブランチが fix/contact-button であることを確認してから作業
停止条件：想定外の関連箇所があれば、変更前に相談してください
```

確認すること（スライド13）：

- [ ] 対象：変更ファイルは `index.html` だけ
- [ ] 内容：差分は次の1行だけ

  ```diff
  - <a class="contact-button" id="contact-button" href="#contact">お問い合わせ</a>
  + <a class="contact-button" id="contact-button" href="#contact">無料相談はこちら</a>
  ```

- [ ] 表示：`index.html` をブラウザで開き、PC幅・スマホ幅で崩れていない
- [ ] 動作：ボタンを押すと「お問い合わせ」欄へ移動する
- [ ] 説明：AIの説明と実際の差分が一致している

> 見せ場：ヘッダーのナビにも「お問い合わせ」があるが、範囲外なので変わっていないことを確認する。

## 04 共有・反映（スライド14・15・23）

```
変更をコミットしてプッシュし、main 向けのPRを作成してください。
コミットメッセージ：お問い合わせボタンの文言を「無料相談はこちら」に変更
PR本文はテンプレートに沿って、確認結果を具体的に書いてください。
```

1. GitHubでPRを開き、**Files changed** で差分を再確認
2. PR本文の「目的／変更内容／変更していないもの／確認結果」を読み上げる
3. **Merge pull request** でマージ
4. **Actions** タブで `pages-build-deployment` が緑になるまで待つ（1〜2分）
5. 公開先 https://protimes-webconsul.github.io/ai-agent-github-practice/ で文言を確認（古い表示なら `Ctrl+F5`）

- [ ] 成功：公開先で「無料相談はこちら」が表示された → PRに確認結果をコメントして完了
- [ ] 失敗・不明：追加変更せず、画面を保存して状態を説明（スライド23）

# ミニ体験シート（スライド21／約15分）

## 課題

練習ページの見出しを、次の文言へ変更してください。

| | 文言 |
|---|---|
| Before | 住まいのお悩み、まとめて解決します |
| After | 点検から修繕まで、ひとつの窓口で |

対象：`index.html` の `id="main-heading"` の文言だけ。

> 全員が同じ行を変更するため、**ミニ体験のPRはマージしません**（講師が確認後にクローズします）。
> マージまでの流れはデモで確認済みです。

---

## 手順

### 1. 現在地とGit状態を確認

未取得の人は先にクローン（デモ01と同じ）。取得済みなら同じフォルダで作業します。

```
現在のフォルダ、リポジトリ、ブランチ、未コミットの変更を一覧で教えてください。
そのあと main を最新化してください。
```

### 2. 作業ブランチを作成

ブランチ名は **`workshop/自分の名前-heading`**（例：`workshop/yamada-heading`）。他の人と重ならない名前にします。

```
workshop/（自分の名前）-heading という作業ブランチを作成してください。
```

### 3. AIへ目的・範囲・確認方法を指示

下の文面をもとに、自分の言葉で指示してください。

```
目的：トップページの見出しを変更する
範囲：index.html の id="main-heading" の文言だけを「点検から修繕まで、ひとつの窓口で」に変更。他は変更しない
確認：変更ファイルと差分を説明してください
Git：作業ブランチにいることを確認してから作業
停止条件：想定外の箇所があれば、変更前に相談してください
```

### 4. 差分と表示を確認

- 差分が `id="main-heading"` の1行だけか
- `index.html` をブラウザで開き、見出しが変わっているか
- PC幅・スマホ幅で崩れていないか

### 5. コミット・プッシュ

```
変更をコミットしてプッシュしてください。
コミットメッセージ：トップページの見出しを変更
```

### 6. 余裕があればPRを作成

```
main 向けのPRを作成してください。本文はテンプレートに沿って書いてください。
```

---

## 完了条件

- [ ] `main` で直接作業していない
- [ ] 指定箇所以外を変更していない
- [ ] 差分を自分で確認した
- [ ] 画面表示を確認した
- [ ] コミット内容を説明できる
- [ ] GitHub上で自分のブランチ（またはPR）の変更を確認できる

**分からなくなったら止まる。分からないまま進めないことが、最も安全な操作。**
